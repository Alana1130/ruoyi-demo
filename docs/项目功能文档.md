# 星旅（XingLv）大学生旅游平台 - 项目功能文档

## 第一章 需求分析

### 1.1 项目背景
星旅是一款面向大学生群体的旅游社交平台，旨在解决大学生旅行中的实际需求，包括旅行费用管理、目的地探索、行程规划、约伴出游等。随着大学生旅游市场的不断扩大，传统的旅游工具难以满足年轻用户的个性化需求，星旅平台应运而生。

### 1.2 目标用户
- **主要用户**：在校大学生
- **年龄范围**：18-25岁
- **需求特点**：预算有限、喜欢社交、注重体验、追求便捷

### 1.3 主要功能
1. **AA记账功能**：团队旅行费用管理，智能计算和分配
2. **目的地探索**：景点、美食、住宿信息浏览和搜索
3. **旅行规划**：行程安排、预算管理、倒计时提醒
4. **约伴功能**：寻找志同道合的旅行伙伴
5. **学校圈**：基于学校的旅游社交
6. **小世界**：虚拟养成和积分系统

### 1.4 主要性能
- **响应时间**：页面加载时间<2秒
- **并发支持**：支持1000+用户同时在线
- **数据安全**：用户信息加密存储，权限控制严格
- **可用性**：系统可用性>99.9%

### 1.5 竞品分析
| 功能 | 星旅 | 传统旅游App | 社交App |
|------|------|------------|---------|
| AA记账 | ✅ 智能分配 | ❌ 无 | ❌ 无 |
| 校园社交 | ✅ 学校认证 | ❌ 无 | ⚠️ 泛社交 |
| 约伴功能 | ✅ 旅游专属 | ❌ 无 | ⚠️ 通用社交 |
| 旅行规划 | ✅ 智能推荐 | ✅ 基础功能 | ❌ 无 |
| 虚拟养成 | ✅ 特色功能 | ❌ 无 | ⚠️ 游戏化 |

```java
public BigDecimal calculatePerPersonAmount(BigDecimal totalAmount, int memberCount) {
    if (memberCount <= 0) {
        return BigDecimal.ZERO;
    }
    return totalAmount.divide(BigDecimal.valueOf(memberCount), 2, RoundingMode.HALF_UP);
}

public void allocateBill(BigDecimal totalAmount, List<TeamMember> members, BigDecimal perPerson) {
    BigDecimal totalAllocated = perPerson.multiply(BigDecimal.valueOf(members.size()));
    BigDecimal difference = totalAmount.subtract(totalAllocated);
    
    for (TeamMember member : members) {
        if (member.isCaptain()) {
            member.setAmount(perPerson.add(difference));
        } else {
            member.setAmount(perPerson);
        }
    }
}
```

### 3.4 技术创新

1. **双端分离架构**：小程序端和管理端完全独立，使用不同的认证机制
2. **Token认证**：小程序端使用Redis存储Token，支持7天有效期
3. **智能AA分配**：除不尽的差额由队长承担，体现公平原则
4. **模块化设计**：清晰的分层架构，便于维护和扩展
5. **响应式界面**：适配不同设备屏幕，提供良好的用户体验
6. **多维度数据搜索**：支持按地区、类型、热度等多维度搜索
7. **实时计算**：消费记录实时汇总，即时计算人均金额
8. **安全保障**：完善的认证和权限控制，敏感信息加密存储

### 3.5 典型使用流程

**AA记账流程**
1. 用户创建旅行队伍，生成加入码
2. 邀请好友通过加入码加入队伍
3. 添加旅行中的各项消费记录
4. 系统自动计算人均金额
5. 生成账单分配，队长承担差额
6. 旅行结束后查看完整账单

**目的地探索流程**
1. 用户浏览首页推荐目的地
2. 搜索特定目的地或类型
3. 查看目的地详情，包括景点、美食、住宿
4. 阅读用户评价，参考他人经验
5. 收藏感兴趣的目的地

**约伴流程**
1. 用户发布约伴帖子，设置目的地、时间、预算
2. 其他用户浏览约伴列表
3. 感兴趣的用户回复帖子
4. 双方在线沟通，确认行程
5. 成功约伴后创建AA队伍
