# 还能加什么功能 · 清单

在已有「目的地、预算、点亮/星星、实践机会、出行服务、写体验、消息、约伴、攻略·游记+话题」基础上，可按下面顺序继续扩展。

---

## 一、优先推荐（体验提升大、实现成本适中）

| 功能 | 一句话说明 | 大致工作量 |
|------|------------|------------|
| **我的行程/行程单** | 保存「计划去的线路」为行程，选日期、写备注、勾选行前清单（证件/物品） | 中：1 表 + 列表/编辑/详情页 |
| **出行清单** | 通用行前清单模板（身份证、学生证、充电宝等），可勾选 | 小：前端列表 + 本地或云端保存 |
| **学生认证 + 学生价** | 用户认证学生身份；目的地/服务页展示「学生票」「青年价」入口或链接 | 中：用户表字段 + 配置/链接列表 |
| **节假日/寒暑假专题** | 如「五一去哪」「毕业旅行」专题页，聚合目的地+线路+实践+约伴 | 中：1 表或配置 + 专题列表/详情页 |
| **实践打卡/证明** | 完成兼职/志愿后打卡或上传证明，形成「实践经历」可展示 | 中：打卡记录表 + 我的页展示 |
| **成长档案** | 一页看全：去过哪、点亮数、写过的体验、实践记录、星星与兑换 | 小：新页从现有接口聚合数据 |

---

## 二、运营与留存

| 功能 | 说明 |
|------|------|
| **签到/任务** | 每日签到、完成任务（写体验、分享）得星星或券 |
| **邀请有礼** | 邀请同学注册并首亮/首单，双方得星星或券 |
| **优惠券/红包** | 签到、点亮、写体验送券，兑换商城或出行服务可用 |
| **消息/订阅提醒** | 约伴有人回复、实践机会上新、订单状态等模板/订阅消息 |

---

## 三、内容与发现增强

| 功能 | 说明 |
|------|------|
| **穷游/省钱榜单** | 按人均预算、性价比排目的地/线路，标签如「500 元两日」「免票」 |
| **目的地/线路评分** | 用户对去过的目的地或线路打星+短评，用于推荐 |
| **体验精选** | 优质攻略/体验在首页或目的地下精选展示 |
| **天气与最佳季节** | 目的地详情展示天气、最佳出行时间（可接第三方或配置） |

---

## 四、社交与约伴增强

| 功能 | 说明 |
|------|------|
| **约伴留言/意向** | 在约伴帖子下留言「想一起」，或简单意向按钮 |
| **同校/同城** | 用户选学校/城市，约伴或动态可筛「同校」「同城」 |
| **拼车/拼房** | 在目的地下发起或加入拼车、拼房（可先做简单发布+列表） |
| **线路讨论区增强** | 讨论区加「约伴」「求攻略」等标签、按时间排序 |

---

## 五、行中与安全

| 功能 | 说明 |
|------|------|
| **预算 vs 实际** | 记录实际花费，和预算规划对比，方便复盘 |
| **当地交通/公交** | 目的地下增加当地公交/地铁入口或链接 |
| **安全与应急** | 目的地页展示紧急电话、安全提示；可选紧急联系人（本地或加密） |

---

## 六、个人与成长

| 功能 | 说明 |
|------|------|
| **技能/兴趣标签** | 用户填技能或兴趣，用于约伴匹配或实践推荐 |
| **证书/成就徽章** | 如「10 城点亮」「穷游达人」「志愿达人」，在个人页展示 |
| **反馈入口** | 设置里「问题与建议」：类型、描述、截图、联系方式 |
